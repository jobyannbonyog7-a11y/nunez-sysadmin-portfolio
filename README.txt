# AILENE ROVERA NUÑEZ — System Administrator Career Portfolio

## Files
- `index.html` — page structure and portfolio content
- `style.css` and `polish.css` — responsive styling, accessible light theme, and subtle animations
- `script.js` — theme switcher, English/Tagalog toggle, mobile menu, scroll progress, reveal effects, and safe code demo
- `images 013.jpg` — profile photo displayed in the hero and About sections

## Run in Visual Studio Code
1. Extract the ZIP folder.
2. Open the `sysadmin_career_portfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension (if it is not installed).
4. Right-click `index.html` and select **Open with Live Server**.
5. Your browser should open the website at a local address such as `http://127.0.0.1:5500`.

You can also double-click `index.html` to preview it, but Live Server is recommended while editing.

## Personalize before submission
- Confirm your name and course in the About section.
- The hero displays the `images 013.jpg` profile photo in a rounded, professional frame. Keep the image in the project folder so it loads correctly.
- Review the Tagalog translations and add your own wording if desired.
- Test every menu link, the theme switcher, language switcher, and the sample-code dropdown/run button.
- Take screenshots at desktop width and mobile width.

## Notes
- No database or login is used, as the brief says they are not required.
- The code lab is a safe, fixed-output learning simulator; it deliberately does not execute arbitrary text typed into the editor or run commands on your computer.
- Google Fonts requires an internet connection. The website remains readable with fallback fonts if offline.
