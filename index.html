01 / THE BIG PICTURE

What is System Administration?

Think of it as taking care of an organization's digital workplace.

⌘

Keep things running

A System Administrator installs, configures, monitors, and maintains computers, servers, accounts, and networks.

♢

Protect information

They help keep systems secure through access controls, updates, backups, and safe working practices.

⌁

Solve problems

When something fails or slows down, they investigate the cause and work toward a reliable solution.

02 / DAY-TO-DAY WORK

Roles & Responsibilities

The behind-the-scenes work that keeps technology dependable.

01💿

Install & maintain OS

Install operating systems and apply updates to keep computers and servers stable.

Windows • Linux
02♙

Manage user access

Create accounts, reset passwords, and give users only the permissions they need.

Accounts • Permissions
03⌁

Monitor performance

Check CPU, memory, storage, and network activity to spot issues early.

Health • Performance
04⟲

Back up & recover

Keep copies of important data and test recovery procedures before an emergency.

Backup • Recovery
05⚙

Troubleshoot issues

Find and fix hardware, software, connectivity, and user-related problems.

Diagnose • Resolve
06♢

Maintain security

Apply security patches, review permissions, and follow safe security practices.

Updates • Protection
